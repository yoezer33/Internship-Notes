## 3. Two-Dimensional Arrays

### Exercise Question

Let us find the average marks of a group of five students for two subjects,
Mathematics and Physics.

Use a two-dimensional array called `grades`.

- Mathematics marks are stored in the first row: `grades[0]`
- Physics marks are stored in the second row: `grades[1]`

Complete the program by:

1. Declaring `grades` as a two-dimensional array of integers.
2. Completing the `for` loops with the correct terminating conditions.
3. Computing the average marks obtained in each subject.
